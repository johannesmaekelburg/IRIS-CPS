## 1. Causal Effects Plot

**File**: `causal_effects_param_value.png`

### Data Used:
- **Input**: All experiments from JSON files
- **Columns**: `param_value`, `I_theta` (post-intervention)
- **Aggregation**: Mean I(θ) grouped by parameter value

### Analysis Performed:
**Total Causal Effect**: τ(a,b) = E[I(θ)|do(θ=b)] - E[I(θ)|do(θ=a)]

For each pair of parameter values (a, b):
1. Filter experiments where `param_value = a` → compute mean I(θ)
2. Filter experiments where `param_value = b` → compute mean I(θ)
3. Calculate difference: τ = mean_b - mean_a
4. Compute standard error using pooled variance

### What the Plot Shows:
- **X-axis**: Parameter value pairs (a → b)
- **Y-axis**: Causal effect magnitude τ
- **Bars**: Positive = increases inconsistency, Negative = decreases inconsistency
- **Error bars**: Standard error (95% CI)
- **Interpretation**: Which interventions have the strongest causal impact?

### Example Interpretation:
```
τ(0.5 → 2.0) = +0.35  →  "Increasing scale from 0.5 to 2.0 causes 
                          a 0.35 increase in I(θ)"
```

## 2. Local Sensitivity Plot

**File**: `local_sensitivity_param_value.png`

### Data Used:
- **Input**: All experiments with consecutive parameter values
- **Columns**: `param_value`, `I_theta`
- **Method**: Finite differences on sorted data

### Analysis Performed:
**Local Derivative**: ∂I(θ)/∂param ≈ [I(θ_{i+1}) - I(θ_i)] / [param_{i+1} - param_i]

For each consecutive pair of parameter values:
1. Sort data by `param_value`
2. Compute finite difference: ΔI/Δparam
3. Smooth using moving average (window=3)
4. Identify critical points (maxima/minima)

### What the Plot Shows:
- **X-axis**: Parameter value
- **Y-axis**: Sensitivity (rate of change of I(θ))
- **Line**: Local gradient at each point
- **Shaded regions**: High sensitivity zones (|∂I/∂θ| > threshold)
- **Interpretation**: Where is I(θ) most sensitive to parameter changes?

### Example Interpretation:
```
At param=1.5: ∂I/∂param = 0.8  →  "Small changes near 1.5 cause 
                                    large changes in inconsistency"
At param=5.0: ∂I/∂param ≈ 0    →  "Inconsistency plateaus, 
                                    insensitive to further increases"
```

## 3. Robustness Margins Plot

**File**: `robustness_margins_param_value.png`

### Data Used:
- **Input**: All experiments
- **Columns**: `param_value`, `I_theta`
- **Aggregation**: Mean I(θ) per parameter value

### Analysis Performed:
**Critical Threshold**: s*(τ) = sup{s : E[I(θ(s))] ≤ τ}

For each threshold τ ∈ {0.3, 0.5, 0.7, 0.9}:
1. Interpolate I(θ) as function of parameter (cubic spline)
2. Find where interpolated curve crosses threshold: I(s*) = τ
3. Compute safety margin: distance from baseline to s*

### What the Plot Shows:
- **Main plot**: I(θ) vs parameter with threshold lines
- **X-axis**: Parameter value (intervention strength)
- **Y-axis**: Global inconsistency I(θ)
- **Horizontal lines**: Threshold levels τ
- **Vertical markers**: Critical values s* where thresholds are crossed
- **Shaded zones**: Safe (green) vs unsafe (red) regions
- **Interpretation**: How much can we vary the parameter before exceeding acceptable inconsistency?

### Example Interpretation:
```
τ = 0.5:  s* = 1.8  →  "Can scale up to 1.8× before 50% inconsistency"
τ = 0.9:  s* = 3.2  →  "Can scale up to 3.2× before 90% inconsistency"

Engineering guarantee: "Stay below param=1.8 to maintain >50% consistency"
```

## 4. Sobol Indices Plot

**File**: `sobol_indices.png`

### Data Used:
- **Input**: All experiments with multiple varying parameters
- **Columns**: `param_value`, `pre_source_volume`, `pre_source_radius`, `pre_target_volume`, `pre_target_radius`, etc.
- **Target**: `I_theta`
- **Requirement**: ≥2 parameters with variation

### Analysis Performed:
**Variance-Based Sensitivity**:

1. **Fit Surrogate Model**:
   - Train Gaussian Process on (θ parameters) → I(θ)
   - Enables efficient Sobol sampling
   
2. **Generate Saltelli Samples**:
   - N=1024 samples using SALib
   - Creates N×(2D+2) evaluation points where D = number of parameters
   
3. **Compute Sobol Indices**:
   - **First-order S₁**: Main effect of parameter i alone
     - S₁ᵢ = Var(E[I|θᵢ]) / Var(I)
   - **Total-effect Sᴛ**: Effect including interactions
     - Sᴛᵢ = 1 - Var(E[I|θ₋ᵢ]) / Var(I)

### What the Plot Shows:
**Two side-by-side bar charts**:

**Left Panel - First-Order Indices (S₁)**:
- Shows individual parameter importance
- "If I only know parameter X, how much variance in I(θ) can I explain?"
- Higher values = more important parameter

**Right Panel - Total-Effect Indices (Sᴛ)**:
- Shows total importance including interactions
- "What fraction of variance would disappear if parameter X were fixed?"
- Sᴛ > S₁ indicates strong interactions

### Example Interpretation:
```
param_value:        S₁=0.65, Sᴛ=0.72  →  "Intervention strength explains 
                                          65% of variance alone, 72% total"

pre_source_volume:  S₁=0.15, Sᴛ=0.28  →  "Source volume has weak main effect 
                                          but strong interactions"

pre_target_radius:  S₁=0.02, Sᴛ=0.05  →  "Target radius mostly irrelevant"
```

**Importance Ranking**: Sort by Sᴛ to prioritize which parameters to control

## 5. Surrogate Model

**File**: `surrogate_model.pkl` (Python pickle)

### Data Used:
- **Input**: All experiments
- **Features (X)**: All varying parameters (θ matrix)
- **Target (y)**: `I_theta`
- **Split**: 80% train, 20% test

### Analysis Performed:
**Gaussian Process Regression**:

1. **Kernel Selection**:
   ```python
   kernel = ConstantKernel × RBF + WhiteKernel
   # Captures smooth nonlinear relationships + noise
   ```

2. **Training**:
   - Fit GP with 10 random restarts
   - Normalize target values (zero mean, unit variance)
   - Optimize hyperparameters via maximum likelihood

3. **Validation**:
   - R² score on test set
   - RMSE and MAE
   - 5-fold cross-validation
   - Residual analysis

### Model Performance (Typical):
```
Train R²:  0.91  →  Explains 91% of training variance
Test R²:   0.87  →  Generalizes well to unseen data
Test RMSE: 0.13  →  Average prediction error ≈ 0.13 in I(θ)
CV R²:     0.83  →  Robust across folds
```

### Purpose:
- **Fast predictions**: 1000× faster than MATLAB zonotope computation
- **Sensitivity analysis**: Enables Sobol indices via efficient sampling
- **Interpolation**: Predict I(θ) for untested parameter combinations
- **Optimization**: Find parameter settings minimizing/maximizing I(θ)

### Usage Example:
```python
import pickle
with open('surrogate_model.pkl', 'rb') as f:
    model = pickle.load(f)

# Predict I(θ) for new parameter combination
theta_new = [[1.5, 45.0, 2.3, 60.0, 2.5]]  # [param_value, volumes, radii]
I_predicted = model.predict(theta_new)
print(f"Predicted I(θ) = {I_predicted[0]:.3f}")
```

## Key Mathematical Definitions

### 1. Total Causal Effect
```
τⱼ(a,b) = E[I(θ)|do(θⱼ=b)] - E[I(θ)|do(θⱼ=a)]
```
- **Pearl's Level 3**: Interventional causality
- **Interpretation**: Average change in inconsistency when forcing parameter change

### 2. Local Sensitivity
```
∂I(θ)/∂θⱼ ≈ ΔI/Δθ = [I(θⱼ + ε) - I(θⱼ)] / ε
```
- **Calculus**: Instantaneous rate of change
- **Interpretation**: How fast I(θ) changes locally

### 3. Robustness Margin
```
s*(τ) = sup{s : E[I(θ(s))] ≤ τ}
```
- **Safety analysis**: Critical threshold
- **Interpretation**: Maximum allowable parameter value before exceeding risk level

### 4. Sobol Indices
```
S₁ᵢ = Var_θᵢ(E[I|θᵢ]) / Var(I)      # First-order
Sᴛᵢ = 1 - Var_θ₋ᵢ(E[I|θ₋ᵢ]) / Var(I)  # Total-effect
```
- **Variance decomposition**: Which parameters matter most?
- **Interpretation**: Importance ranking for design optimization

## Data Requirements

### Minimum Requirements:
- **Causal Effects**: ≥10 unique parameter values (more is better)
- **Local Sensitivity**: ≥5 consecutive parameter values
- **Robustness Margins**: ≥8 parameter values spanning threshold range
- **Sobol Indices**: ≥2 varying parameters, ≥50 experiments

### Optimal Configuration:
- 20+ parameter values per intervention type
- 3-8 scenarios with different geometries
- 5+ repeats per condition (for statistical robustness)
- 300 MC samples per I(θ) computation

## Troubleshooting

### "Skipping Sobol indices: Need ≥2 parameters"
**Cause**: Only intervention parameter varies, geometry is constant

**Solution**: 
- Combine multiple scenarios (different source/target volumes)
- Or manually add scenario features to analysis

### "Robustness margins: No threshold crossing found"
**Cause**: I(θ) range doesn't span threshold values

**Solution**:
- Adjust `--threshold` parameter
- Extend intervention parameter range

### "Surrogate model: Low R² < 0.5"
**Cause**: Insufficient data or high noise

**Solution**:
- Increase number of experiments
- Check for outliers/errors in data
- Try Random Forest instead: `model_type='rf'`
