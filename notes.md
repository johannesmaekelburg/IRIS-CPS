# Project Notes — Causality-Inconsistency-Uncertainty

## What this project does

Research project investigating whether **uncertainty causes inconsistency** in cyber-physical systems (CPS). Uses Pearl's interventional causal framework (do-calculus) with constrained polynomial zonotopes as the uncertainty representation.

**Core question**: Given two zonotopes (source + target) connected by an affine UPR mapping `y = F*x + f`, does manipulating the source zonotope's uncertainty (via interventions θ) cause the propagated source to become inconsistent with the target?

**Global inconsistency metric** `I(θ) ∈ [0,1]`: probability that a random point from the propagated source zonotope does NOT lie inside the target. Computed via Monte Carlo sampling (expensive) or approximated via AABB Jaccard (cheap but biased).

## The two surrogate models

### 1. DeepSets surrogate (`surrogate/`) — THE FOCUS

- **~1,250 parameters**. Lightweight, fast (~2 µs/sample inference).
- **Architecture**: Per-dimension features → shared phi MLP (4→16→16) → masked sum-pool → rho MLP (26→32→1) → sigmoid
- **Input features per dimension (4)**: `[delta_c_i/σ, ||G1_i||/σ, ||G2_i||/σ, cos(G1_i, G2_i)]`
- **Global features (10)**: log volume ratio, normalised centre distance, 8-class UPR-type one-hot
- **Supports dim ∈ {2, 3, 4}** via zero-padding + boolean mask
- **Trained on**: `data/measurements_v6/` (12 CONVIDE scenarios) + `data/measurements_cps_v6/` (72 CPS scenarios)
- **Training**: inductive scenario split (stratified by dimension), MSE loss, Adam, ReduceLROnPlateau
- **Evaluation**: compared against AABB and MFMC baselines
- **Used for**: paper figures RQ1-RQ4, gradient-based counterfactual search

### 2. GINE GNN surrogate (`src/learned_surrogate/`) — alternative approach

- Much larger (~50k+ params). Uses torch_geometric GINEConv.
- Self-supervised pretraining (volume, containment, pairwise AABB, affine map) + supervised fine-tuning
- Generates its own synthetic data via `src/causal_engine.py`
- More complex, hasn't replaced DeepSets for the paper

## Data

### Training data for DeepSets (`data/measurements_v6/` and `data/measurements_cps_v6/`)

- **measurements_v6/**: 12 CONVIDE scenarios (4×2D, 4×3D, 4×4D), 10,240 experiments each
- **measurements_cps_v6/**: 72 CPS domain scenarios (ALL 2D), 10,240 experiments each
- **Total**: 84 scenario files × 10,240 = ~860k experiments
- Generated by MATLAB pipeline (expensive MC sampling)
- Each experiment has: pre/post state, intervention params (scale_factor, center_delta, correlation_strength), inconsistency scores (I_theta, MFMC, AABB Jaccard, etc.)

### Dimension distribution problem

- **2D**: 4 CONVIDE + 72 CPS = **76 scenarios** (90%)
- **3D**: 4 CONVIDE = **4 scenarios** (5%)
- **4D**: 4 CONVIDE = **4 scenarios** (5%)
- Massively imbalanced → model likely undertrained on 3D/4D

### Intervention parameter space (θ)

| Parameter | Bounds | Effect |
|-----------|--------|--------|
| `scale_factor` | [0.5, 5.0] | Scale generators (widen/shrink uncertainty) |
| `center_delta` | [0.0, 0.2] | Shift center |
| `correlation_strength` | [0.0, 0.95] | Add dependent generator via Givens rotation |

## Our goal: improve DeepSets with synthetic data

**Problem**: The DeepSets model has limited 3D/4D training data (only 4 scenarios each vs 76 for 2D).

**Plan**: Generate lots of synthetic 2D, 3D, and 4D zonotope pairs with known I(θ) labels using `src/causal_engine.py` (the pure-Python engine), then retrain the DeepSets surrogate.

### What we can leverage

- `src/causal_engine.py` already has:
  - `Zonotope` class, `affine_map`, `contains_point`/`contains_points_batch`
  - `mc_consistency_probability`, `compute_I_theta`, `compute_I_theta_aabb`
  - `apply_compound_intervention` for θ = (scale_factor, center_delta, correlation_strength)
  - `create_convide_scenarios()` and `create_cps_scenarios()` for the 48 real scenarios
- `src/learned_surrogate/generate_data.py` has a data generation pipeline but targets the GNN format

### What we need to build

1. **Synthetic scenario generator**: random zonotope pairs (source + target) with random F, f mappings across 2D, 3D, 4D
2. **I(θ) labeling**: for each synthetic scenario, sample θ values and compute I(θ) via MC
3. **Output format**: must match `results_scenario_*.json` structure that `surrogate/dataset.py` expects (or we adapt the dataset loader)
4. **Balance**: generate equal amounts of 2D, 3D, 4D data

## What we did

### 1. Model comparison on real data (v6)

Implemented 4 new model variants in `surrogate/models_v2.py` alongside the original DeepSets baseline:

| Model | Params | Val MSE | Approach |
|-------|--------|---------|----------|
| `deepsets` (v1) | 1,249 | 0.00127 | phi(4→16→16) → sum → rho(26→32→1) |
| `deepsets_v2` | 8,769 | 0.00119 | phi(5→32→32→32) → sum+max pool → rho(67→64→32→1) |
| `flat_mlp` | 7,809 | 0.00177 | flatten all features → MLP(23→64→64→32→1) |
| `siamese` | 14,017 | 0.00984 | encode raw geometry → combine → head |
| `set_transformer` | 10,513 | 0.00089 | self-attention (1 layer, 2 heads, d=32) → mean pool → rho |

**Diagnosis**: off-diagonal error bands came from held-out 3D/4D scenarios — the model had too few 3D/4D training examples.

### 2. Synthetic data generation

Generated 160 synthetic scenarios (10×2D + 75×3D + 75×4D) with diverse geometry:
- Generator types: diagonal (40%), near_diagonal (30%), dense (30%)
- F mapping types: identity (50%), near_identity (30%), random (20%)
- Overlap regimes: high (50%), partial (30%), low (20%)
- Binary search on AABB Jaccard for target placement
- Post-processing balancing to cap overrepresented I(θ) bins
- Output: `data/synthetic_v6/` (matches MATLAB JSON format, stores propagated source so UPR = identity)

### 3. Next: retrain on combined real + synthetic

- Train best models (set_transformer, deepsets_v2) on real + synthetic data
- Evaluate on held-out real scenarios only (same inductive split)
